# adela-demos 课件质量评价与开发规范 (Courseware Quality Standard)

本规范是 `adela-demos` 课件集合的**最高质量基准**。所有已上线及新开发的课件，其详细程度、结构完整性与教学闭环均需**完全对齐《相对速度小课堂》(`demos/galilean-transform/relative-velocity/index.html`)** 的标准。

---

## 1. 课件核心结构五步法 (The 5-Tab/Section Standard)

每个完整的奥数/科学互动课件必须形成从“直觉认识”到“动手实验”再到“实战解题与测验”的完整教学闭环，标准包含以下板块：

```text
[Header Banner]  彩色渐变大 Banner，含主标题、副标题、4 个特点徽章 (Badges)
       │
       ├── ① 【认识概念 / 核心原理】
       │     └─ 6 张图文并茂的核心概念卡片 (带 Emoji + 浅显定义 + 生活例子 + 核心公式)
       │     └─ 1 个经典生活化对比表格 (对比不同视角/情形)
       │     └─ 1 个最关键核心公式高亮卡片 (Formula Card)
       │
       ├── ② 【基础交互实验室 / 动态模拟 1】
       │     └─ 核心概念的基础动画模拟（支持滑块控制、播放/暂停/重置、坐标/状态实时回显）
       │     └─ 参照系/视角切换过渡动画（smoothstep 过渡）
       │
       ├── ③ 【进阶拓展实验室 / 动态模拟 2】
       │     └─ 二维拓展、复杂变体或多种情形对照
       │     └─ 多坐标系叠加/锚定切换、速度矢量三角形或动态面积割补
       │
       ├── ④ 【奥数实战应用题 / 经典题型解法】
       │     └─ 经典题型拆解（相遇/追及、顺水/逆水、过桥/错车、蝴蝶比例、抬腿/假设等）
       │     └─ 【交互式求解计算器】：支持输入参数即时计算并动画反馈
       │     └─ 解题思维步骤卡片（①找关键量 ②统一方向/基准 ③套用模型秒解）
       │
       └── ⑤ 【互动小测验 / 知识闯关】
             └─ 4~5 道精选单选题，点击即时反馈对错（绿色√ / 红色×）
             └─ 每道题点击后必须展示详细的图文原理解析
```

## 2. 视觉与交互硬性标准

1. **布局与风格**：
   - 统一遵循 `docs/demo-design-guideline.md` 的 `:root` 调色板（`--c1: #5b8def`, `--c2: #ffb14e`, `--c3: #36c5a6`, `--c4: #f4739b`, `--c5: #9a7cf0`）。
   - 卡片圆角 `18px~24px`，柔和投影 `0 8px 24px rgba(60,70,120,.10)`。
2. **Tab 切换与自适应**：
   - 顶部 Tab 药丸按钮带色彩圆点指示器，切换平滑淡入。
   - 必须完美适配手机端屏幕（单列堆叠、滑块宽度自适应、点击区域 $\ge 44\text{px}$）。
3. **动画与物理连续性**：
   - 状态切换拒绝突兀瞬切，采用 $400\sim 680\text{ms}$ `smoothstep` 缓动。
   - 支持 `prefers-reduced-motion` 降级，避免定时器内存泄漏（统一单一 `requestAnimationFrame` 驱动）。
4. **即时反馈与趣味性**：
   - 滑块调节必须带实时数值与方向标注（如 `+4.0 m/s`）。
   - 小测验与求解器点击有清晰的声光/色彩反馈及趣味文案提示。

## 3. 课件验收 Checklist (质量打分表)

- [ ] **Banner**：是否有渐变大 Banner + 4 个教学特性徽章？
- [ ] **概念卡片**：是否有 6 张核心概念拆解卡片 + 生活例子？
- [ ] **对比表格**：是否有不同情形/视角的对比归纳表格？
- [ ] **双重实验**：是否至少有 2 个不同维度的交互实验室（如基础+进阶）？
- [ ] **题型求解器**：是否有可输入的奥数经典应用题即时求解与动画验证？
- [ ] **互动小测验**：是否有 4~5 道带解析的即时答题系统？
- [ ] **响应式与无依赖**：纯前端单文件（或同目录打包），无构建依赖，手机与桌面端均无错位。
