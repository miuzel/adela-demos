# 演示视觉交互规范

本规范服务于“让小学生看懂、敢操作、能复述”的物理演示。所有新页面优先使用原生 HTML/CSS/JavaScript，避免无必要的依赖和加载等待。

## 设计令牌

建议在 `:root` 集中声明并复用：

```css
:root {
  --color-ink: #17233d; --color-muted: #60708f; --color-primary: #4169e1;
  --color-accent: #7b61d9; --color-success: #21b89a; --color-warning: #f2a33a;
  --color-danger: #e76886; --color-bg: #f5f7ff; --color-surface: #fff;
  --font-sans: "PingFang SC", "Microsoft YaHei", system-ui, sans-serif;
  --radius-sm: 10px; --radius-md: 16px; --radius-lg: 24px;
  --shadow-card: 0 18px 50px rgba(39,56,115,.12);
  --space-1: 4px; --space-2: 8px; --space-3: 12px; --space-4: 16px;
  --space-5: 24px; --space-6: 32px; --space-7: 48px;
  --duration-fast: 160ms; --duration-normal: 240ms; --ease: cubic-bezier(.2,.8,.2,1);
}
```

配色使用深色正文与低对比背景，主色用于可操作控件；正文至少保持清晰对比。圆角从 10/16/24px 三级使用，卡片统一柔和阴影。动效只服务状态变化，默认 `240ms var(--ease)`，并尊重 `prefers-reduced-motion`。

## 通用组件交互模式

- **页头**：左侧项目名/课件名，右侧状态或重置；移动端可隐藏次要文字。`header` 有清晰的 `h1`，不依赖 logo 图片。
- **Tab 切换**：使用按钮而非链接；当前项有颜色、底线或填充状态，并同步切换面板。设置 `aria-selected`、`role=tab`/`tabpanel`（若适用），键盘可聚焦。
- **滑块 + 数值回显**：滑块旁立即显示带单位和方向的数值；`input` 事件实时更新画布、公式和文本，数字变化不能只靠颜色表达。
- **播放/暂停**：同一按钮在播放时显示“暂停”语义（图标之外提供 `aria-label`），再次点击保持当前位置；动画循环用 `requestAnimationFrame`。
- **重置**：页头提供明确的重置按钮，恢复所有输入、视角、计时器和播放状态；不刷新页面，不清除用户上下文。
- **画布/舞台**：画布或 CSS 舞台必须配文字图例、坐标/单位和关键对象标签；颜色、位置、文字三者共同表达状态；窄屏时内容不溢出。
- **按钮层级**：主行动使用实心主色（如“开始体验”），次行动使用描边/浅底，危险操作才用警示色。按钮有 hover、focus-visible、disabled 状态，点击区域不小于 44px。
- **反馈色语义**：绿色=正确/完成/运行中，橙色=提示/等待，红色=错误/不可行；必须同时配合文字、图标或形状，不能只依赖色盲可混淆的颜色。

## 本项目的可执行约定

### 伽利略变换实验室

保留三段 Tab 顺序“运动实验室 → 概念小卡片 → 相遇与追及”。速度滑块范围为 -8～+8 m/s，向右为正；每次输入都更新速度回显、箭头、公式与舞台位置。地面、A 车、B 车、飞鸟四种视角必须有当前态高亮和文字说明。播放按钮不得重置位置，重置按钮恢复 `vA=4`、`vB=2`、`t=0` 与地面视角。

### 相对速度小课堂

保持自包含单文件即可离线使用。动画中的参照物、速度方向和单位应有文字标注；选择题/计算题提交后立即反馈，并用文字解释原因。所有控制在手机宽度下纵向排列，动画暂停后仍可阅读当前帧；新增题目沿用绿色正确、红色纠错并提供可重试路径。

## 检查清单

提交前确认：无外部必需资源；所有入口和脚本相对路径有效；手机宽度无横向滚动；Tab、滑块、播放/暂停、重置可用；键盘 focus 清楚；动效有减弱模式；公式、速度和颜色都带单位或文字解释。
